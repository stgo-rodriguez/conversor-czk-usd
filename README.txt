CONVERSOR CZK ↔ USD CON CÁMARA

Publicación:
1. Descomprima el ZIP.
2. Publique todos los archivos en un alojamiento HTTPS (GitHub Pages, Cloudflare Pages, Netlify, etc.).
3. Abra la dirección en el teléfono.
4. Android: menú del navegador > Agregar a pantalla de inicio / Instalar.
5. iPhone: Safari > Compartir > Agregar a pantalla de inicio.

OCR offline:
- La interfaz y el conversor funcionan offline una vez instalada la PWA.
- El motor OCR y el modelo se descargan y guardan durante la primera apertura con internet.
- Para garantizar que el OCR quede disponible, realice un primer escaneo mientras tiene conexión.
- Luego los escaneos y las conversiones se ejecutan localmente.

Privacidad:
Las fotografías se procesan dentro del navegador y no se envían a un servidor de la aplicación.
