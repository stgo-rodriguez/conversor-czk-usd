# Conversor CZK ↔ USD con cámara

Aplicación web progresiva compatible con Android y iPhone.

## Publicar con GitHub Pages

1. Cree un repositorio público en GitHub, por ejemplo `conversor-czk-usd`.
2. Suba todos los archivos de esta carpeta directamente a la raíz del repositorio.
3. Abra **Settings → Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama **main** y la carpeta **/(root)**.
6. Pulse **Save**.

La dirección tendrá normalmente este formato:

`https://SU-USUARIO.github.io/conversor-czk-usd/`

## Instalación

### Android
Abra la dirección con Chrome y seleccione **Instalar aplicación** o **Agregar a pantalla de inicio**.

### iPhone
Abra la dirección con Safari, pulse **Compartir** y seleccione **Agregar a pantalla de inicio**.

## Primer uso del OCR

Abra la aplicación con conexión y realice al menos un primer escaneo para guardar el motor OCR y su modelo. Después podrá utilizarse sin conexión.
